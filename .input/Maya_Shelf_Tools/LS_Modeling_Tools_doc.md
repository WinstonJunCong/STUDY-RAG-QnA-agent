## **Project Tools**

### ![](../Images/LS_Modeling_Tools_doc//media/image23.png) **Mono Asset Checklist Tool**

Asset tool for Monopoly project that checks and fixes (selected) issues:

  - Naming and Hierarchy

    - Asset Naming and World Objects<br>
        Check asset name and unwanted objects at world level<br>
        <br>

    - Hierarchy Naming<br>
        Search for incorrect hierarchy<br>
        <br>

    - Namespace<br>
        Check for existing namespace<br>
        <br>

    - Display Layers<br>
        Check for missing and extra display layers<br>
        <br>

    - Display Layers Membership<br>
        Check for layer memberships<br>
        <br>

  - Shader

    - Shader Naming<br>
        Check if shader assigned are correctly named<br>
        <br>

    - Default Shader<br>
        Check if mesh assigned to default shader<br>
        <br>

    - Unused Shader<br>
        Search for unused shaders<br>
        <br>

  - Surfacing

    - Color Set<br>
        Check no multiple existing color set on the geometries and no color sets for characters<br>
        <br>

    - Export Vertex Color<br>
        Check for \"Export Vertex Color\" is enabled for geometries with color set<br>
        <br>

    - UV Set Editor<br>
        Check for geometries with color set does not have UV shells<br>
        <br>

    - UV CH Editor<br>
        Check if Characters contain \"map1\" and \"Expressions\" uv sets<br>
        <br>

  - Clean-Ups

    - Unknown Plugins<br>
        Check for unknown plugins<br>
        <br>

    - History<br>
        Check geometry does not have any history<br>
        <br>

    - Freeze Transform<br>
        Check all non-anim geometries have freeze transformation applied<br>
        <br>

    - Reset Pivot<br>
        Check all non-anim geometries have pivot at origin<br>
        <br>

    - Toggle soft edge display<br>
        Check soft/hard edge display are toggled for all geometries<br>
        <br>

    - Ngons<br>
        Search for ngons in geometries<br>
        <br>

  - Extra

    - Citizen Pivot<br>
        Check all character pivots matches perfect citizen<br>
        <br>
