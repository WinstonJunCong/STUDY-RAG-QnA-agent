# Game Animation Training I

**Game Animation Training I**  
**LEVEL 1 \- Basic Body Mechanics**

## **🧍‍♂️ Idle**

* Please create an idle loop motion that shows the character is **ready for combat**  
* The motion should contain some subtle breathing-like action to accompany the loop  
* To show variance and so that it does not feel repetitive, please create a total of 3 loops  
* Each loop should have the same number of frames which is around 60-80 frames per loop  
* Please ensure that the first and last pose are the same  
* The duration of this motion is 1.5 MDs

## **🚶‍♂️ Locomotion**

### **🚶🏻‍♀️ Walk | 🏃🏻‍♀️ Jog | 💨 Run**

* Please choose either a walk, jog or run to work on  
* Create a simple loop that shows a progressive movement and that it should stem from your Idle pose (It should be in the same universe as your Idle motion)  
* **The world (global) control should be moving**   
* To show variance and so that it does not feel repetitive, please create a total of 3 loops (Each loop should feel slightly different from one another)  
* Please ensure that your motion has an average speed of;   
  * **Walk \- around 90 \~ 150 cm/s**  
    * **Jog \-  around 300 cm/s**   
    * **Run \- around 480 \~ 690 cm/s**   
* Please ensure the feet are planted onto the ground and that there are no feet sliding  
* Please ensure that the first and last pose are the same  
* The duration of this motion is 2 MDs  
  


  ### **🦘 Jump Set**

* Please create a simple vertical jump that showcases your understanding of body mechanics  
* Please note that the jump should be broken down into 3 parts;

  1️⃣ JumpStart

  2️⃣ JumpLoop

  3️⃣ JumpEnd

* When creating this motion, please create it as a single motion first before splitting it into 3 parts  
* Your motion should start and end from the Idle pose  
* Please ensure that the start and end of the loop have the same poses  
* The duration of this motion is 1.5 MDs

## **🔁 Turn 90/180**

* Please create a simple 90 degree or 180 turn to the left or right  
* **Do take note that the world (global) control has to turn as well to its respective direction**  
* This motion should be around 30 \~ 45 frames  
* The duration should be 1.5 MDs

## **🤾🏻‍♀️ Stagger**

* Your character should be reacting to damage either from the front, back, left or right (Please choose just one direction)  
* Please ensure that the motion is progressive  
* **The world (global) control should be moving**  
* Your motion should start and end from the Idle pose  
* This motion should be around 15 frames  
* The duration should be 1.5 MDs


## **🤡 Emotes**

* This motion is geared more towards acting  
* An emote is a little action a character does in a game (eg. waving, dancing, clapping, etc)  
* This motion should not exceed 150 frames  
* Your motion should start and end from the Idle pose  
* The duration is 2 MDs
