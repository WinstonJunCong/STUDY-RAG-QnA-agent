# 📹 Preview (Playblast)

	In 3ds Max, a Playblast is known as a **Preview**. There are 3 ways to create a preview;

**Method 1**

- Click on the [+] icon at the top left of your viewport

![Enter image alt description](../Images/3ds_Max_Doc/YxN_Image_4.png)

**Method 2**

- Click on the Tools at the menu

![Enter image alt description](../Images/3ds_Max_Doc/euj_Image_5.png)

**Method 3**

- Press [ Shift ] + [ V ]

After you have clicked on “Create Preview Animation…”, you should see this window

![Enter image alt description](../Images/3ds_Max_Doc/NPk_Image_6.png)

1. Under the Preview Range, ensure the frame range is set correctly

![Enter image alt description](../Images/3ds_Max_Doc/rNT_Image_7.png)

1. Under the Frame Rate, make sure your FPS is set correctly…

![Enter image alt description](../Images/3ds_Max_Doc/0LY_Image_8.png)

…As for the “Every Nth Frame”, looking at the above image, it means that it is playblasting on every frame. For example, if you set it to 5, it means that it is playblasting on every 5 frames

1. Under Image Size, you are can set the correct resolution by heading to the Render Setup

![Enter image alt description](../Images/3ds_Max_Doc/3ie_Image_9.png)

![Enter image alt description](../Images/3ds_Max_Doc/KnH_Image_10.png)

1. Under “Display in Preview”, please select what you would like to show

![Enter image alt description](../Images/3ds_Max_Doc/pKZ_Image_11.png)

1. Under “Overlay”, please turn on the Frame Numbers and Camera/View Name. Safe frames will depend on the situations (consult your lead if necessary)

![Enter image alt description](../Images/3ds_Max_Doc/03h_Image_12.png)

1. Under “Visual Style”, you can bump up the Image Quality to 100 while the rest can be left as it is

![Enter image alt description](../Images/3ds_Max_Doc/QYy_Image_13.png)

1. For “Output”, once you have clicked File, it will open up another window…

![Enter image alt description](../Images/3ds_Max_Doc/Jxn_Image_14.png)

…which you need to click on Setup, which again opens up another window…

![Enter image alt description](../Images/3ds_Max_Doc/MIQ_Image_15.png)

Depending on the client, choose the type of compressor that suits the project. By default, we can go with the standard H.264 compressor. Once you have selected your compressor choice, click on “Setup”...

![Enter image alt description](../Images/3ds_Max_Doc/d6i_Image_16.png)

…Another window will open, you will need to turn on Zero Latency and set the Ratefactor to 1

![Enter image alt description](../Images/3ds_Max_Doc/P07_Image_17.png)

1. Once all that is settled, please ensure you playblasting based on the correct viewport and hit “Create”

![Enter image alt description](../Images/3ds_Max_Doc/1Hz_Image_18.png)

## **📉 Motion Trail**

There are 2 ways to enable the motion trail;

	**	Method 1**

1. Select object

2. Right click ➡ Object Properties

3. Tick on “Motion Path”

![Enter image alt description](../Images/3ds_Max_Doc/TQ2_Image_23.gif)

**Method 2**

1. Select object

2. Go to the command panel for motions

3. Select “Motion Paths”

4. Tick on “Always Show Motion Path”

## **👨‍👩‍👦 Parenting**	

### **👫 Link and Select**

In 3ds Max, ***Link and Select is the equivalent of Maya’s parent***

**To link objects ⤵**

1. Click Select and Link icon (icon will turn blue)

![Enter image alt description](../Images/3ds_Max_Doc/uJp_Image_110.png)

2. Select the object (child) and drag it to any other object (parent)

![Enter image alt description](../Images/3ds_Max_Doc/DmF_Image_111.gif)

**To unlink objects ⤵**

1. Select the child

2. Click Unlink

![Enter image alt description](../Images/3ds_Max_Doc/AJG_Image_112.png)

![Enter image alt description](../Images/3ds_Max_Doc/cXY_Image_113.gif)

### **🔗Link Parent**

In 3ds Max, ***Link Parent is the equivalent of Maya’s parent constraint***

![Enter image alt description](../Images/3ds_Max_Doc/7hJ_Image_114.png)

1. Select the child

2. Go to the motion panel

3. Select Parameters

4. Select “Transform : Position/Rotation/Scaling”

![Enter image alt description](../Images/3ds_Max_Doc/d4m_Image_115.png)

6. Select Link Constraint and click OK

7. Move the time frame to the frame that you want to start the constraint

8. Click Add Link

9. Select your parent object (the current frame you have selected is the active parent frame)

10. Click “Link to World” to return back to the default

![Enter image alt description](../Images/3ds_Max_Doc/I5Q_Image_116.png)

![Enter image alt description](../Images/3ds_Max_Doc/EfN_Image_117.gif)

**❗❗ Make sure to click Add Link again to deactivate it at the end ❗❗**
