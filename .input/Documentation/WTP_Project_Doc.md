# **🐶 MADDOG**

## ![](../Images/WTP_Project_Doc/media/image5.png) **Export FBX**

- One click to detect **props** and **characters** to be exported to a preset folder path

## ![](../Images/WTP_Project_Doc/media/image3.png) **Export FBX Cam**

- One click to detect the **camera** in the scene to be exported to a preset folder path

- The camera will need to have **"\_UE"** at the back of the camera name for it to work

## ![](../Images/WTP_Project_Doc/media/image10.png) **Export ABC (Alembic)**

- One click to export alembic cache in the scene to be exported to a preset folder path

## ![](../Images/WTP_Project_Doc/media/image1.png) **Open Maya Port**

- Connects Lemoncore panel to Maya
